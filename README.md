# NoNo's Boutique

## Project Description

NoNo's Boutique is a fashion website showcasing clothing collections for women, men and children.

## Website Pages

- Home – Introduction to the boutique.

- About Us – Information about the boutique.

- Services – Information about available services.

- Gallery – Displays clothing images with category filters and search functionality.

- Contact Us – Allows visitors to submit enquiries.

## Technologies Used

- HTML5

- CSS3

- JavaScript

- Visual Studio Code

- GitHub Pages

## Features

- Navigation between website pages.

- Fashion image gallery.

- Gallery category filters.

- Search functionality.

- Contact form with required-field validation.

- Responsive viewport settings.

- SEO metadata.
